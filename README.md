#Inventory Dashboard

A web-based inventory dashboard built for a small grocery store. 
It displays product data including stock status, revenue, and 
product counts in a clean, modern interface.

## Features
- Live product table with stock status
- Dashboard cards showing total products, in stock, sold out and revenue
- Filterable and sortable table with DataTables
- Clean dark UI with Lucide icons

## Tech Stack
- Python & Flask (Backend)
- Jinja2 (Templating)
- HTML & CSS (Frontend)
- DataTables (Interactive table)

## How to run
1. Install dependencies:
   pip install flask
2. Start the app:
   python app.py
3. Open your browser at:
   http://127.0.0.1:5000
